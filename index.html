🚀 Git Commands Reference Guide

This is a comprehensive guide to Git commands for version control.

Learn the essential commands to manage your code repositories effectively.

📘 Basic Git Commands

Command Action Example
git init Initialize a new Git repository in the current directory git init
git clone [url] Create a local copy of a remote repository git clone https://github.com/user/repo.git
git status Show the current state of the working directory and staging area git status
git add [file] Add specific file changes to the staging area git add index.html
git add . Add all changed files in current directory to staging area git add .
git commit -m "[message]" Save staged changes with message (-m flag means "message") git commit -m "this is message of v1"
git log Display the commit history with full details git log
git log --oneline Show commit history in compact single-line format git log --oneline
git log [file] Show commit history for a specific file git log .gitignore
git show [commit-id] Display details and changes of a specific commit git show a3f5b2c
git diff Show differences between working directory and last commit git diff
git diff [file] Show changes in a specific file git diff index.html
git push Upload local commits to the remote repository git push origin main
git pull Download and merge changes from remote repository git pull origin main
git remote -v Display all remote repositories linked to local repo git remote -v
git fetch Download changes from remote without merging git fetch origin
git reset [file] Remove file from staging area (unstage) git reset index.html
git rm [file] Delete file from working directory and stage deletion git rm old-file.txt
📝 Note about -m flag: The -m flag stands for "message" and allows you to write commit message inline. Without it, Git opens a text editor for the message.

🚫 Git Ignore

Command Action Example
touch .gitignore Create a .gitignore file to specify files to ignore touch .gitignore
echo "[pattern]" >> .gitignore Add a pattern to gitignore file echo "node_modules/" >> .gitignore
git rm --cached [file] Remove file from Git tracking but keep in directory git rm --cached secrets.txt
git check-ignore -v [file] Check if file is ignored and which rule causes it git check-ignore -v file.log

🌿 Git Branches

Command Action Example
git branch List all local branches (* shows current branch) git branch
git branch -a List all branches including remote branches git branch -a
git branch [name] Create a new branch with specified name git branch feature-login
git checkout [branch] Switch to a different branch git checkout main
git checkout -b [name] Create new branch and switch to it immediately git checkout -b feature-signup
git switch [branch] Switch to another branch (newer alternative to checkout) git switch develop
git switch -c [name] Create and switch to new branch in one command git switch -c hotfix-bug
git branch -d [name] Delete a branch (only if merged) git branch -d feature-login
git branch -D [name] Force delete a branch (even if not merged) git branch -D old-feature
git branch -m [new-name] Rename the current branch git branch -m better-name
git push origin --delete [branch] Delete a remote branch git push origin --delete feature-old

🔀 Git Merge & Conflicts

Command Action Example
git merge [branch] Merge specified branch into current branch git merge feature-login
git merge --no-ff [branch] Merge with explicit merge commit (preserves history) git merge --no-ff feature-x
git merge --abort Cancel merge and return to pre-merge state git merge --abort
git status Check merge conflicts (shows CONFLICT messages) git status
git diff View conflicts in files during merge git diff
git add [file] Mark conflict as resolved after manual editing git add conflicted-file.js
git commit Complete merge after resolving all conflicts git commit
git log --merge Show commits causing merge conflicts git log --merge
git checkout --ours [file] Accept your version during conflict git checkout --ours app.js
git checkout --theirs [file] Accept incoming branch version during conflict git checkout --theirs app.js
git rebase [branch] Move or combine commits to new base branch git rebase main
git rebase --continue Continue rebase after resolving conflicts git rebase --continue
git rebase --abort Cancel rebase and return to original state git rebase --abort
⚠️ Understanding Merge Conflicts: Conflicts occur when Git can't automatically merge changes. You must manually edit files, choose which changes to keep, then mark as resolved with git add.

📦 Git Stashing

Command Action Example
git stash Save current uncommitted changes temporarily git stash
git stash save "[message]" Save changes with a descriptive message git stash save "work in progress"
git stash list Show list of all stashed items with their index git stash list
git stash apply Apply most recent stash without removing it git stash apply
git stash apply stash@{0} Apply specific stash by index (0 is most recent) git stash apply stash@{2}
git stash pop Apply most recent stash and remove it from list git stash pop
git stash pop stash@{0} Apply and remove specific stash by index git stash pop stash@{1}
git stash drop stash@{0} Delete specific stash without applying it git stash drop stash@{0}
git stash clear Remove all stashed items (clean the stash) git stash clear
git stash show Show changes stored in most recent stash git stash show
git stash show -p Show full diff of changes in most recent stash git stash show -p
💡 Understanding stash@{0}: The {0} is an index number. stash@{0} is the most recent stash, stash@{1} is the one before that, etc. Think of it like a numbered list where 0 is the newest item.

⚙️ Git Configuration

Command Action Example
git config --global user.name "[name]" Set username for all Git repositories globally git config --global user.name "John Doe"
git config --global user.email "[email]" Set email address for all Git repositories globally git config --global user.email "john@example.com"
git config --list Display all Git configuration settings git config --list
git config user.name Check current username configuration git config user.name
